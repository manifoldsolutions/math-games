What is this?

The picture shows the curve

γ(t) = Σ cn eint,   0 ≤ t ≤ 2π,

in the complex plane, where the sum has finitely many terms and every cn is a complex number.

Each term cneint is a vector of length |cn|. While t runs from 0 to 2π it turns round |n| times: counterclockwise when n > 0, clockwise when n < 0. The term c0 stays where it is. Put the vectors tip to tail, and the last tip is at γ(t). “Show drawing” shows exactly this.

At t = 2π every term is back where it started, so the curve is closed.

It works the other way round too: a closed curve γ has the Fourier coefficients cn = (1/2π) ∫02π γ(t) e−int dt, and a few terms already draw it well. The samples “Triangle” and “Square” are five terms of such a series.
